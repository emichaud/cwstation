Run the simulation

Start the band in a terminal; it streams to this tape. Stations call at random pitches, speeds, and strengths — with AFC on, the decoder re-tunes to each one. 

uv run python manage.py cw_simulate --stream {{ request.user.username }} --server {{ request.scheme }}://{{ request.get_host }} --save {{ request.user.username }}

With --save, Ctrl-C stores the run as a session scored against what the simulated stations actually sent — your accuracy under those knob settings. Turn on the tape's 🔊 to listen to the band.
