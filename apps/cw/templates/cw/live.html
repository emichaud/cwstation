Feed the tape

On the machine the radio is plugged into, run the live monitor and stream it here. The command mints its own short-lived API token and revokes it on exit. 

uv sync --extra live   # once
uv run python manage.py cw_monitor_live --stream {{ request.user.username }} --server {{ request.scheme }}://{{ request.get_host }} --save {{ request.user.username }}

Drop --save if you don't want the run stored as a session. The tone is auto-detected from the first seconds of audio; pass --tone 700 to pin it. No radio handy? Practice and send replays live on the Monitor.
