This is where you set sending up

You don't key messages from here — you send on the Live tape (out to the radio) or make a WAV on the Decode page. Both start from the defaults and keys you set below.

{# ── Sending defaults ── #}
⚙

Default speed & sidetone

Where your keyer starts every time. You can still nudge either one per message.

{# ── Callsign ── #}
📻

Your callsign

Fills {mycall} in every message and the ADIF STATION_CALLSIGN. Leave blank to use your username.

{# ── Message keys ── #}
⌨

Message keys

Your keyer memories — like a contest keyer's F-keys. Type /cq in a composer (or tap a keycap) and the message drops in with its {tags} filled. Built-ins: {mycall} {call} {rst}. Edit here; saves on blur.

{# ── Custom tags ── #}
🏷

Custom tags

Reusable values you drop into any message. Define rig = KW4420 once, then {rig} expands everywhere. Names are lowercase; you can't reuse mycall, call, or rst.
