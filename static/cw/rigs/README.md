# Custom rig photos (optional)

The Rig Setup page shows a built-in illustration for each radio type
(base / compact / mobile / handheld / SDR). If you want a real photo of a
specific radio, drop a **licensed** image here named by its Hamlib model
number and it will replace the illustration in the model rows.

- Filename: `<model>.png` (or `.webp` / `.jpg`) — e.g. `3085.png` for the
  Icom IC-7300. Find the model number in the rows (`#3085`) or with
  `rigctl -l`.
- Recommended: ~200×140, transparent or dark background, trimmed to the rig.

We deliberately ship **no** manufacturer photos — those are copyrighted.
Only add images you have the right to use (your own photos, or images with a
license that permits redistribution).
